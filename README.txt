BRAVE RABBIT - Android project (Kotlin, WebView)

Build on GitHub (no software needed on your PC):
1. Create a new repository on github.com
2. Upload everything from this folder, INCLUDING the hidden .github folder
   (if it does not upload, create the file .github/workflows/build.yml in the GitHub web editor and paste build.yml from this project)
3. Open the Actions tab -> "Build APK" -> wait for the green tick
4. Open the finished run -> Artifacts -> BraveRabbit-APK -> download, unzip, install app-debug.apk on the phone

Default Instagram PIN: 1258 (change it in Settings).
